# WirelessCam（Windows 版の配布）

iPhone を、Windows 11 の Web カメラとしてワイヤレスで使うアプリ「WirelessCam」の、Windows 版のインストーラを置いている場所です。

- 紹介・使い方・サポート：https://wirelesscam-app.web.app
- ダウンロード：[最新版の WirelessCam-Setup.exe](https://github.com/touyayoyo-glitch/wirelesscam-releases/releases/latest/download/WirelessCam-Setup.exe)
- 入れ方（Windows の確認が 2 回出ます）：https://wirelesscam-app.web.app/windows

## 動作環境

- Windows 11（64 ビット）
- iPhone（iOS 27 以上）に WirelessCam のアプリ
- iPhone と PC が同じ Wi-Fi につながっていること

## プライバシー

映像は家の Wi-Fi の中だけで、暗号化して PC に届きます。開発者は利用者の情報を集めません。詳しくは [プライバシーポリシー](https://wirelesscam-app.web.app/privacy) をご覧ください。

このリポジトリには、配布用のファイルだけを置いています。
